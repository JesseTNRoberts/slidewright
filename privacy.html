Slidewright privacy policy

Effective October 29, 2026. Slidewright is made by Jesse Roberts.

Slidewright is a slide deck editor that runs entirely in your web browser at www.jessetnroberts.com/slidewright. There is no Slidewright account and no Slidewright server that receives your slides. This page explains what Slidewright reads, where it keeps things, and who else is involved.

Your decks

Decks you open are read and edited in your browser. Slidewright does not upload them anywhere except to the place you choose when you save, which is your computer, your Google Drive or your GitHub repository.

When you click Present with Slidewright on a deck, the deck sends its own contents to the Slidewright page in your browser. Nothing is sent to a server.

Google Drive

If you choose to open from or save to Google Drive, Slidewright asks Google for permission to use the drive.file scope. With it, Slidewright can see and change only the files you pick in Google's file picker or create with Slidewright. It cannot list, read or change anything else in your Drive.

Slidewright uses that access only to

  • download the deck you picked so you can edit or present it,
  • save your changes back to that file, or create a new file in the folder you pick,
  • read the file's name, version and earlier versions so you can compare or restore them.

The access token Google issues is kept only in the memory of the open page. It is not written to disk, it is not sent to any server other than Google's, and it expires after about an hour. Choosing Sign out of Google Drive revokes it. You can also remove Slidewright's access at any time at myaccount.google.com/connections.

Slidewright does not store, share, sell or transfer Google user data, does not use it for advertising, and does not use it to train AI or machine learning models. Slidewright's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

GitHub

If you sign in with GitHub, a small sign-in relay run by Slidewright on Cloudflare Workers exchanges GitHub's one-time code for an access token and hands the token straight back to your browser. The relay does not store or log the token. You can also paste a personal access token instead.

The GitHub token is saved in your browser's local storage so you stay signed in, and it is sent only to GitHub. Sign out of GitHub in Slidewright removes it, and you can revoke Slidewright at github.com/settings/applications.

What stays in your browser

  • A recovery copy of the deck you are editing, so a crash or closed tab doesn't lose your work.
  • The list of recently opened files (in Chrome and Edge).
  • Your GitHub token, if you signed in, and a note of which GitHub Pages sites match which repositories.

These live only in your browser on your device. Clearing this site's data in your browser removes them.

Other services your browser contacts

  • GitHub Pages hosts Slidewright, and like any web host it receives standard request information such as your IP address.
  • Google receives requests when you use Google Drive (sign-in, the file picker and the Drive API), and when a deck or page loads fonts from Google Fonts.
  • GitHub receives requests when you use GitHub features.

Slidewright itself uses no analytics, no advertising and no tracking cookies.

Children

Slidewright is a tool for teachers and presenters and is not directed at children under 13.
