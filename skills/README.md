# Skills

Claude skills that work with Slidewright.

- [`lecture-deck-builder/`](lecture-deck-builder/SKILL.md): builds a lecture deck on a Design art board, then exports it with [`board-to-reveal`](../board-to-reveal/README.md) to the reveal.js format Slidewright edits and presents.

To use one, add its folder as a skill in Claude (Settings → Capabilities → Skills). The copy here is kept in step with the one in use; update both together.
